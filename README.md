## Stock Portfolio Tracker (Python)

### 📌 Project Description
This project is a simple Stock Portfolio Tracker developed using Python.
It allows users to enter stock names and quantities, and then calculates the total investment value based on predefined stock prices.

The program runs in a console environment and demonstrates basic Python programming concepts.

---

### 🚀 Features
- Predefined stock price dictionary
- User can enter stock name and quantity
- Calculates total investment value
- Displays portfolio summary
- Option to save result in a text file

---

### 🛠 Technologies Used
- Python
- Dictionary
- While Loop
- For Loop
- Conditional Statements
- File Handling
- User Input

---

### 📂 How to Run the Program

1. Install Python (if not installed)
2. Download or clone the repository
3. Open terminal / command prompt
4. Navigate to the project folder
5. Run the following command:
     Stock Portfolio Tracker (Python)
